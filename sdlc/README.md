# SDLC-пилот: статусы контрагентов

Эта папка делает передачу задачи между ролями проверяемой и независимой от
переписки. GitHub хранит неизменяемые версии артефактов; LangGraph-оркестратор
может передавать исполнителю только ссылку на соответствующий handoff.

## Поток

1. Бизнес создаёт Issue.
2. Аналитик готовит пакет в `sdlc/artifacts/<feature-id>/`.
3. После PR аналитика в `main` workflow создаёт GitHub Issue для разработчика.
4. Разработчик берёт только этот Issue и handoff, создаёт feature-ветку и PR.
5. QA сверяет реализацию с `test-plan.md` и `evals/<feature-id>.jsonl`.
6. Только успешный QA-пакет допускает релиз.

## Структура

- `agents/` — контракты ролей для людей и AI-агентов.
- `artifacts/` — бизнес- и аналитические документы конкретной фичи.
- `handoffs/` — машиночитаемые пакеты передачи.
- `evals/` — проверяемые сценарии качества.
- `scripts/` — локальные validation gates.

Артефакты нельзя изменять задним числом: уточнение создаётся новым коммитом и
проходит новый PR. В `handoff` фиксируются входы, допущения и обязательные
проверки следующего этапа.
