# SDLC-CURSOR-001 — пилот Cursor SDLC

Источник: workflow «Создать Git-native SDLC feature», PR [#38](https://github.com/RuslanMarkin/CRM_Almaz/pull/38).

## Потребность

Проверить, что аналитический пакет, подготовленный агентом в Cursor, автоматически
передаётся через GitHub PR в следующий этап SDLC после human approval.

## Ценность

Подтвердить, что Git/GitHub — единственный источник истины о состоянии feature,
а Cursor остаётся только рабочей средой агента без отдельной системы статусов.

## Границы пилота

В объёме — этап `analysis` для `SDLC-CURSOR-001` и штатный переход к
`development-plan`. Изменения продуктового кода CRM, схемы данных и бизнес-логики
контрагентов в этот пилот не входят.
