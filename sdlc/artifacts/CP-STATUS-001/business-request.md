# CP-STATUS-001 — статусы контрагентов

Источник: [GitHub Issue #3](https://github.com/RuslanMarkin/CRM_Almaz/issues/3)

## Потребность бизнеса

На странице «Контрагенты» сотрудник должен видеть статус каждой компании и
назначать его при создании или редактировании карточки.

## Список статусов

| Код | Отображение |
| --- | --- |
| `normal` | Норм |
| `missing_scans` | Не хватает сканов |
| `blacklisted` | ЧС |
| `debtor` | Должник |

## Ценность

Статус позволяет быстро видеть риск контрагента без открытия карточки и
дополнительных сверок.
