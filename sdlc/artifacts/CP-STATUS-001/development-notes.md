# Результат разработки: CP-STATUS-001

## Что реализовано

- В модель контрагента добавлен статус: `normal`, `missing_scans`, `blacklisted` или `debtor`.
- Для новых и существующих записей задано значение по умолчанию `normal`.
- Статус можно выбрать при создании и изменении контрагента.
- Badge статуса виден в списке и карточке контрагента.
- API отвергает неизвестное значение статуса.

## Изменения данных

Миграция `drizzle/0012_counterparty-status.sql` добавляет только одну колонку
`counterparties.status`. Никакие существующие таблицы, строки или бизнес-правила
не меняются. Это отдельно защищено автотестом.
