# Контракт разработчика

## Вход

- GitHub Issue, созданная workflow передачи;
- `handoff` и все перечисленные в нём артефакты.

## Выход

- отдельная feature-ветка и PR;
- миграция схемы, серверная валидация, UI и автоматические тесты;
- ссылка на commit SHA и результаты проверок в QA-пакете.

## Gate

Нельзя менять бизнес-правила из спецификации без возврата задачи аналитику.
Нельзя сливать изменения при неуспешных `pnpm check` или `pnpm test`.
