# Контракт аналитика

## Вход

- бизнесовая GitHub Issue;
- актуальный код и схема данных;
- действующие ограничения продукта.

## Выход

- `business-request.md`;
- `analysis-spec.md` с допущениями и границами задачи;
- `test-plan.md`;
- `handoff` со статусом `ready_for_development`.

## Gate

Не передавать задачу разработчику, если нет списка полей, API-изменений,
миграции, критериев приёмки, рисков и явных допущений.
